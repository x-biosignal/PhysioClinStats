# PhysioClinStats: clinical inference engine

Mixed-effects / MMRM longitudinal models, single-case (N-of-1) designs,
estimands with multiple imputation, causal mediation, declared
target-trial emulation, and per-estimate uncertainty. Heavy modelling
backends are optional, guarded Suggests.
